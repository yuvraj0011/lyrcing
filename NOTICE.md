# Third-party data and services

Lyrcing bundles no lyrics and no album art. It uses these sources at runtime or build time:

| What | Source | Terms |
| --- | --- | --- |
| Time-synced lyrics | [LRCLIB](https://lrclib.net) public API (community-contributed lyrics) | See LRCLIB's terms. Lyrics remain the property of their rights holders. |
| Cover art | iTunes Search API | Apple's API terms |
| Emoji keywords (English, Hindi, Punjabi, Urdu, Gujarati, Marathi, Bengali, Tamil, Telugu, Kannada, Malayalam, Nepali, Arabic, Persian, Korean, Japanese, Russian, Thai) | [Unicode CLDR](https://github.com/unicode-org/cldr) annotations, bundled as `Resources/emoji_index.json` (generated by `scripts/build_lexicon.py`) | [Unicode License v3](https://www.unicode.org/license.txt) |
| English sentiment | Apple `NaturalLanguage` framework (on-device) | Part of macOS |
